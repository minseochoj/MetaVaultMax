## Installation

1. Clone the repository: `git clone https://github.com/harutosati/MetaVaultMax.git`
2. `cd MetaVaultMax`
3. Install in editable mode: `pip install -e .`

## Configuration

MetaVaultMax is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
